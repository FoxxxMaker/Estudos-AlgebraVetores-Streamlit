# Estudos Algebra Vetores Streamlit

Calculadora educacional de vetores em duas dimensões, construída com Python, NumPy e Streamlit.

O projeto é um espaço de estudo para praticar álgebra linear e desenvolver uma interface web simples. A implementação está em desenvolvimento.

## Objetivo

Permitir que o usuário informe dois vetores 2D e acompanhe o resultado das operações, entendendo a matemática usada em cada etapa.

## Operações planejadas

- Soma de vetores
- Subtração de vetores
- Multiplicação de vetor por escalar
- Produto escalar
- Verificação de ortogonalidade
- Ângulo entre vetores
- Visualização gráfica em 2D

## Estrutura atual

```text
.
├── app.py                # Ponto de entrada futuro da interface Streamlit
├── MathCodes.py          # Lógicas matemáticas das operações com vetores
├── requirements.txt      # Dependências do projeto
└── .streamlit/

```
